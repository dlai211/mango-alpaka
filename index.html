MANGO Flow Anatomy

A conditional normalizing flow supplies the physics. An Alpaka kernel supplies the speed. This page walks the whole path, then shows where the time actually goes — including the half where the kernel still loses.

02

How the conditional flow works

One point's journey through the marginal. The conditioning network makes the map different for every collision energy; everything after the boundary happens inside the kernel.

Direction
The inverse is where the cost lives. A cubic has no closed-form inverse, so the reference solves it with 40 bisection steps and one Newton correction. In PyTorch that is roughly 40 rounds of small kernel launches — and it is why the inverse is the half the Alpaka kernel wins by 254×.
03

How Alpaka works

One C++17 source file, compiled once per backend. The accelerator type is a template parameter, not a rewrite.

04

They are not alternatives

The normalizing flow is the model; Alpaka is the runtime. The real comparison is between two implementations of the same marginal — and it turns on one thing: how many launches per call.

Why the forward still loses. The kernel wins by removing per-call overhead. The forward has almost no overhead to remove — it is already a handful of vectorised operations — so what is left is the host→device copy of raw, which grows with batch size. Closing it needs device pointers, an interface change rather than a kernel one.

Inverse. No closed form, so both solve for t inside the selected bin.

PyTorch · 40 bisection steps, then Newton
low, high = torch.zeros_like(x), torch.ones_like(x)
for _ in range(self.inverse_iterations):
    mid = (low + high) * 0.5
    x_mid, _ = self._hermite(mid, x0, height, width, d0, d1)
    low  = torch.where(x_mid < x, mid, low)
    high = torch.where(x_mid < x, high, mid)
t = (low + high) * 0.5

x_t, dx_dt = self._hermite(t, x0, height, width, d0, d1)
t = (t - (x_t - x) / dx_dt.clamp_min(tiny)).clamp(0, 1)

u = (u0 + width * t).clamp(0.0, 1.0)
Alpaka · the same loop, per thread
T low = T(0), high = T(1);
for (int it = 0; it < inverse_iterations; ++it) {
    T const mid = (low + high) * T(0.5);
    T xm = T(0), dxm = T(0);
    hermite(mid, y0, h, w, d[idx], d[idx + 1], xm, dxm);
    if (xm < target) { low = mid; } else { high = mid; }
}
T t = (low + high) * T(0.5);

T xt = T(0), dxt = T(0);
hermite(t, y0, h, w, d[idx], d[idx + 1], xt, dxt);
t = clamp01(t - (xt - target) / dxt);

u[i] = clamp01(u0 + w * t);
